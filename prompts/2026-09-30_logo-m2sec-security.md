## Prompt consolidado (reconstruído, pronto para reuso)

> Crie uma logomarca para a `m2sec_security` que passe uma imagem de **segurança de dados/cibersegurança** — não segurança física/patrimonial (evite escudo medieval arredondado + cadeado sólido genérico, isso lê como empresa de vigilância/portaria).
>
> Use um **cadeado como ícone central** (precisa ser reconhecível em qualquer tamanho, inclusive foto de perfil pequena), mas construído com **elementos de circuito/placa de PCB** — trilhas, "vias" (pontinhos nos cruzamentos), grade — para deixar claro que é proteção **digital**, não física. Coloque esse cadeado dentro de um **badge hexagonal "tech"** (não um escudo medieval).
>
> Evite literalidade exagerada: nada de texto de pacote TCP/IP real, comando shell completo ou código binário como protagonista — fica ilegível em tamanho pequeno e parece clichê de "hacker de filme" em vez de autoridade corporativa. Se quiser reforçar o tema digital, use **dígitos binários bem sutis só como textura de fundo**, não como elemento central.
>
> Paleta: fundo escuro/quase preto (autoridade), com **detalhes em dourado** (e um toque de prata/silver nas linhas internas) para aumentar a credibilidade visual — sem exagerar a ponto de parecer "bling".
>
> Entregar: versão completa (ícone + wordmark "M2SEC" + subtítulo "Cyber Security" + tagline) e uma versão só-ícone para foto de perfil circular.
