Dúvidas

Perguntas frequentes

Isso é golpe?+
Não. A remoção de dados pessoais é um direito garantido pela LGPD (Lei Geral de Proteção de Dados). Fazemos as solicitações formais em seu nome, com total transparência.
Funciona mesmo?+
Sim — cada plataforma tem um processo próprio de solicitação de remoção, que seguimos à risca. Você recebe um relatório de conclusão de cada remoção.
Quanto tempo demora?+
Varia por plataforma, mas normalmente leva alguns dias úteis após o envio da solicitação. Te mantemos informado em cada etapa.
Preciso pagar pra fazer o diagnóstico?+
Não. O diagnóstico inicial, pelo WhatsApp, é 100% gratuito e sem compromisso.
Meus dados ficam seguros com vocês?+
Sim. Usamos seus dados exclusivamente para realizar as solicitações de remoção, seguindo as mesmas diretrizes de proteção de dados que defendemos.
